### Degree requirements: why zero
1. **Acalog bot challenges.** Twenty catalog hosts refused after the challenge threshold (four
   consecutive 202 challenges). 316 program pages were never requested. They are now listed in an
   exception queue (`challenged_hosts` in coverage and review.md, and on the dashboard), together with
   alternate official sources found on the school's own site. Nothing is retried or evaded.
2. **Coursedog catalogs** (ABAC, Coastal Georgia, Point) build the program list with JavaScript. The
   static HTML has no program links. The official alternates are "Download Catalog as PDF" and
   "Program Maps".
3. **Courseleaf variants** (Dalton State `/schoolofbusiness/<program>/`, Georgia Tech
   `/programs/<slug>/`) did not match the Tennessee and Kentucky URL patterns. Catalog links that name
   an undergraduate degree are now ranked as program links. A catalog-focused re-crawl is needed to
   measure the effect.

## Shared extractor fixes (each has a regression test from the real page and a mutation check)

- **credit_table:** a one-cell section row ("Foreign Languages") ended up as an exam's score. Stacked
  levels ("50 62") are now `stacked_cells_review`. A header cell repeated as a score ("Score") is now
  `score_cell_not_a_score`. When a course column's header doesn't say "course" ("AMSC Exemption",
  "Credit"), the column is now found from its course codes.
- **cost_table:** "With Relative", "Off- Campus", and "In-state Resident" (residency, not a housing
  budget) are now mapped correctly. Military-rate tables (`special_population_rate`), per-credential
  budgets (`program_specific_budget`) and "Tuition Per Standard Program Length"
  (`program_length_amount`) are exceptions and are never used as annual tuition.
- **merit_table:** outside, external, military and veteran scholarship lists and international waiver
  pages are skipped. A tier whose amount says "Not eligible" is no award. A short lead above a table
  supplies its year ("Fall 2027 Award Tiers" gives entering class 2027-28), but only the year.
- **transfer_sentences:** "45 of the last 60 hours" now stores 45. Grade rules that name courses
  ("ENGL 1101", "Composition courses") or only encourage a grade are scoped, not general.
- **dual_enrollment:** testimonials ("GMC earns a 4.0 GPA"), worked examples, "recommended" GPAs, and
  institutional GPA, SAP or good-standing rules are not high-school eligibility thresholds.
- **common_data_set:** a C1 total printed as 0 is now `c1_zero_total`.
- **All extractors:** an http-only source is `source_not_https`. It is an exception, never a failed
  promotion.

## Correction to promoted data

`data/institutions/uwa/credit_policies/2026-27.json` (Alabama, promoted 2026-10-03) recorded
`min_hs_gpa: 2.75`. The cited line says a 2.75 GPA *earned in 12 hours of UWA dual-enrollment
coursework* allows test-free admission. It is not a high-school requirement. The value was removed
and the reason is in the record's notes. The import keeps the old payload as a revision.
